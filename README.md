# Melange Mercantile

A brand system and cinematic website for a fictional, Dune-inspired luxury trading company. *Spice · Trade · Influence.*

This is a personal project. I designed the brand first, then built the website to tell its story.

## The brand

Melange Mercantile is a discreet trading company that supplies melange, the most valuable substance in the Dune universe, to the Great Houses. The brand is meant to feel prestigious, calculated, and quiet: cinematic desert luxury, not neon sci-fi.

- **Color:** 13 tokens in three families. Cold, dark grounds (about 85% of any screen), metals sampled from the logotype (about 13%), and spice tones used sparingly (about 2%). Every text color is checked for contrast.
- **Logo:** the mark is vectorized into versions for light, dark, and lit "metal" use.
- The full spec is in [`BRAND.md`](BRAND.md).

## The website

The site tells one story, *from the deep desert to your hall*, in eight chapters. Each one answers the next question a buyer would ask:

1. **Arrival:** Who are you?
2. **The Source:** Where does it come from?
3. **The Melange:** Why does it matter?
4. **The Reserve:** What can I have?
5. **The Passage:** How does it reach me?
6. **Discretion:** Why trust you?
7. **Allocation:** How do I ask?
8. **Verify:** Is mine genuine?

The story and every copy decision are written up in [`STORY.md`](STORY.md), and the design brief is in [`DESIGN-BRIEF.md`](DESIGN-BRIEF.md).

## Built with

React and Vite, three.js for the 3D scenes (including a custom-shaded melange vial), Lenis for smooth scrolling, and Framer Motion.

## Run it locally

```bash
cd site
npm install
npm run dev
```
